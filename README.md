# Semantic HTML5 & Accessible Dashboard

## Overview

A responsive dashboard foundation built with semantic HTML5, CSS, and JavaScript. The project demonstrates accessible navigation, structured data tables, validated forms, and modal dialogs using web accessibility best practices.

## Features

- **Semantic HTML5:** Uses elements such as `header`, `nav`, `main`, `section`, `article`, `aside`, and `footer`.
- **Accessible navigation:** Includes labelled navigation regions, a skip-to-main-content link, and current-page indicators.
- **Records table:** Displays sample records with a caption and properly scoped column headers.
- **Accessible form:** Uses associated labels, `fieldset`, `legend`, and built-in HTML validation.
- **Modal dialog:** Demonstrates a native HTML dialog with open and close controls.
- **Responsive layout:** Uses CSS Grid and a media query to adapt the dashboard to smaller screens.
- **Keyboard focus indicators:** Makes keyboard navigation easier to follow.

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension, or serve the folder using a local web server.
4. Use the Overview and Records navigation links to explore the pages.

## Validation

The `index.html` and `pages/records.html` files have been checked with the W3C HTML Validator and returned no errors or warnings at the time of validation.

## Scope and Limitations

This is a frontend demonstration. The records shown are sample data, and the form does not save records to a backend or database.

## Purpose

This project demonstrates semantic HTML structure and foundational accessibility practices for an enterprise-style dashboard.
